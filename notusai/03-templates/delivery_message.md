# Delivery Message Templates

How to send the completed draft to the customer professionally.

---

## Delivery message (WhatsApp + Email simultaneously)

```
Namaste [CA Name] sir,

Aapke client [Client Name] ke ASMT-10 ka draft reply ready hai. 24 ghante ka
commitment tha, [N] ghante mein deliver kar raha hoon.

📄 Attached: Reply_[ClientName]_ASMT10_[Date].pdf

Quick summary of the draft:
• Notice demand: ₹[X,XX,XXX]
• Our defense: claim ₹[Y] as legitimate, reverse ₹[Z] (the genuine error)
• Predicted outcome: [HIGH/MEDIUM/LOW] probability of dropping without DRC-01
• Key citations used: Section 16(2), Rule 36(4), Bombay HC ruling in [Case]

Recommendations for filing:
1. [Specific action 1, e.g., "Attach the vendor's amended GSTR-1 confirmation"]
2. [Specific action 2, e.g., "File within 7 days to stay well clear of deadline"]
3. [Specific action 3]

📌 Payment link: [Razorpay link for ₹999/1999/4999]

Please review the draft. Agar koi heavy editing chahiye to please share —
prompt improve karne mein madad milegi. 7 din ke baad I'll check in with you
about filing outcome.

Best,
[Your Name]
NotusAI | notusai.in
```

---

## What to attach

A single PDF file with:

**Page 1:** Cover summary (the bullets above)
**Page 2-N:** The formal reply letter
**Last page:** Citations list + questions for practitioner (if any)

Use Google Docs to format, then File → Download → PDF.

**Filename format:** `Reply_[ClientName]_[NoticeType]_[Date].pdf`
Example: `Reply_SharmaTextile_ASMT10_25Nov2025.pdf`

---

## When sending the payment link

Send Razorpay link **with the draft**, not before. This is critical:
- Customer can review quality first → builds trust
- They pay only when satisfied → high conversion rate
- Looks confident (not desperate)

Set Razorpay link description:
```
NotusAI - ASMT-10 reply draft for [Client Name]
Service: AI-drafted GST notice reply
Includes: Formal letter, citations, strategy summary
```

---

## 24-hour follow-up after delivery

```
Sir, kal jo draft bheja tha [Client Name] ka, koi feedback?
Agar payment process kar diya ho to confirm kar dena, mein invoice email
kar dunga GST ke liye.
```

If they haven't paid yet after 48 hours, ONE polite nudge:
```
Sir, aapne draft check kiya? Quality acchi lagi ya kuch improve karna hai?
Honest feedback chahiye, aur agar usable lagi to payment link pending hai.
```

If after 72 hours still no payment, ONE final message:
```
Sir, draft delivery ke 3 din ho gaye. Agar koi issue tha quality mein please
bata dijiye — agar usable nahi tha to mein refund/cancel kar deta hoon and
move on. Agar usable thi to please complete the payment.
```

After that, mark as "delivered but unpaid" in your tracker. Don't deliver another draft to that customer until they clear the previous bill.

## After 7 days — outcome check-in

```
[Name] sir, jo ASMT-10 draft tha [Client Name] ka — file ho gaya?
Department se koi response aaya?

Agar order favorable aaya ho to please confirm — testimonial mein use kar
sakta hoon (anonymously, sirf "Pune-based CA firm" type credit).

Agar koi DRC-01 ya escalation hua to bata dijiye, follow-up reply bhi
draft kar deta hoon.
```

Tracking outcomes builds your moat. After 50 outcomes, you have data nobody else has.
